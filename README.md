# 💳 Digital Wallet (Java Console Application)

This project is a simple **Digital Wallet** system developed in **Java**. It allows users to register, log in, add money, withdraw funds, and view their wallet balance — all through a user-friendly console interface.

> 💡 Ideal for beginners and freshers showcasing their Java and file handling skills in interviews like **FIS**.

---

## 📌 Features

- 👤 User Registration
- 🔐 Secure Login
- 💰 Add Money to Wallet
- 💸 Withdraw Money
- 🧾 Check Balance
- 💾 Data stored in a `.txt` file (simulating a database)

---

## 🧑‍💻 Technologies Used

- Java (Core)
- Object-Oriented Programming (OOP)
- File Handling
